One line of the worst possible advice an AI could give — confident, tidy,
specific enough to follow, and disastrous enough to regret. The program
writes the line to `entry.txt`, ready for the "Worst AI Advice: The 48-Hour
Tight Line Open" bounty on make.fun.

> To fix slow Wi-Fi, microwave your router for 30 seconds — the heat boosts the signal.

## Run

```sh
python3 main.py
```

This writes the line to `output/entry.txt`, or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set.
